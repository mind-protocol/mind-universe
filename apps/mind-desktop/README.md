# Mind Desktop

Embodied, graph-native projection of the locally materialized Universe.

## Observer controls

- left drag: orbit;
- right drag: pan;
- mouse wheel: zoom;
- `WASD`, `ZQSD`, or arrow keys: move on the horizontal plane;
- `E` / `C`, `Space` / `Page Down`: move vertically;
- `Shift`: accelerate;
- `Alt`: precise movement;
- `R`: return to the initial viewpoint.

These controls move the independent Observer only. Actor movement must go
through an authorized action intent and a capability receipt.

## Graph-owned visual projection

Mind Desktop renders typed visual descriptors. It does not map canonical
predicates or L4 roles itself:

- the graph selects entity geometry and motion primitives;
- the graph supplies the idle bond material;
- a bond remains visually idle merely because it exists;
- only an `energy_transferred` event carrying revision, tick, execution,
  intention, transfer identity, measured epistemic state, and a resolved visual
  descriptor creates a travelling effect;
- `energy_transfer_released` removes the completed effect.

The renderer interpolates frames between attested endpoints. It never invents
an energy transfer from a relation, an intent, or a running process.
